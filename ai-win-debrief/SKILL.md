# AI 赢单蒸馏分析（Win Debrief）

## 触发条件

- 用户说「蒸馏 XX AI 赢单」「蒸馏一下 XX 的赢单经验」—— 通常是单人/多人赢单复盘会
- 用户说「把 XX 的 AI 赢单内容整理分析」「梳理出结构性信息」—— 多人赢单汇总
- 会议标题含「蒸馏」「赢单」「复盘」

## 🚨 输出框架铁律（2026-08-26 用户明确纠正）

用户明确拒绝过「五行业打法对照表 + 三档方法论」这类框架化输出。正确框架是：

```
逐人赢单过程（客户 → 起点 → 推动动作 → 成交结果 → 后续） → 跨人沉淀路径和打法
```

- ✅ 要：每个客户怎么赢的（原版本 → 什么触发 → 谁拍板 → 什么话术生效 → 后续机会）
- ❌ 不要：行业×打法矩阵表、按金额档（9.9/29.7/99）堆统计
- 结构：按人分组讲过程（卡片1-2），再提炼通用路径+决策人地图（卡片3）

### 单类型边界（V3 定稿，勿混）

| 类型 | 边界 | 打法定位 |
|------|------|---------|
| 🆕 新签 | 9900 → 99000 | 客户第一次真正买 AI（破冰） |
| 📈 增购 | 99000 → 297000 / 990000 | 已有正式包后往上走（放量） |

Deep Grill 自审时先问：三类分开了吗？

### 三个核心洞察（置顶 Highlight，红色大字号）

1. **AI 第一负责人**：CAIO / CIO / HR 负责人 / 技术负责人 = 29.7 万及以下的关键人；**CEO 一定是 99 万的关键决策点**，推 99 前先确认一把手态度
2. **场景用量是货币**：升级靠消耗数据说话，不靠关系。用量测算表 = 一步到位的核心武器
3. **组织推动力是放大器**：一把手站台 + 大赛/培训造势，把自然消耗变成可控增长

一句话：找到对的人（1）→ 用数据证明用量（2）→ 用组织动作放大消耗（3）

## 赢单过程采集要素（蒸馏会上逐个客户问）

1. **原版本**：买升级包前是什么（9900 / 9.9 万 / 29.7 万 / 免费）
2. **触发点**：用量快用完？续约节点？大赛造势后？功能痛点？
3. **推动动作**：用量测算表？跃迁计划？全员培训？高层建联？试用包？
4. **决策人**：IT 负责人 / HRBP / CIO / CEO / 董事长，谁拍板、谁背书
5. **成交结果**：哪个档位、一把到位还是逐级升、有没有打包（策略中心等）
6. **后续**：Q4 机会、下次升级计划、风险信号

## 五条可复制路径（2026-08 实测沉淀）

| 路径 | 代表案例 | 适用场景 | 关键动作 |
|------|---------|---------|---------|
| 🅰️ 用量测算一步到位 | 库马/众擎/徕芬 | 用量明确超标 | 租户真实数据测算表 + 「必超/不浪费」预期管理，直接跳档（9900→29.7） |
| 🅱️ 大赛造势→用量→升级 | 凯迪仕/宝龙达/星辉 | 组织推动力强 | AI 效率先锋大赛/全员培训把消耗拉起来 → 用完节点推升级 |
| 🅲 续约+跃迁组合拳 | 和生/众擎/钱海通 | 续费节点客户 | 跃迁增量逻辑；⚠️ 9.9 到期再买 29.7 增量只算 19.8 万不满足，未到期叠加买才行 |
| 🅳 决策人管理痛点 | 天波/蓝星 | 价格谈不动 | 找到 AI 第一负责人的管理诉求（高管看纪要无权限/想管控用量），功能只是抓手——功能为管理服务 |
| 🅴 老客户增量滚动 | 珊珊 5 单 | 已购客户 | 快用完时去聊，被拒就续 9.9 等下次，保持接触频率 |

## 决策人识别地图（= AI 第一负责人地图）

- **29.7 万及以下**：CAIO / CIO / 技术负责人 / HR 负责人——找到他就成功一半；HR 拍板时拿外部工具开销背书（众擎案例：codex 每人月 100 美金）
- **99 万：CEO 是唯一关键决策点**——C-level 推 99 胆怵（不知道怎么跟老板解释花公司的钱），需要老板站台 + 人效数据支撑
- 老板风格决定节奏：凯迪仕董事长「一个个买」vs 柒牌老爷子「一把到位」
- 预算卡壳三招：版本切换腾挪预算 / 安全权益下放先小步用 / 邀约老板降决策难度

## 升级信号清单（量化触发器，2026-08-26 沉淀）

| 档位 | 触发信号 |
|------|---------|
| 🟢 9900→99000（新签） | 消耗率 ≥ 2 倍（多案例验证）；只用智能纪要单模块其他未激活；激活人数上涨/办过大赛 |
| 🟡 99000→29.7（增购） | 用量测算超档（真实数据 700 万+ → 600 万包）；半年内烧完 9.9 万；额度快用完+场景在长（豆包工作伙伴跑起来） |
| 🔴 29.7→99（增购） | 消耗曲线测算 8-10 个月用完；激活人数到千级（1000/4000/白领 6000）；一把手已公开表态拥抱 AI |

💡 反直觉（用户 2026-08-26 修正）：99 万不一定靠人数，1000 多人企业也到 99——**关键是使用场景**（某企业靠妙搭场景消耗起来），不是「全员推」这个模糊表述。

## 失败模式速查（5 个反例，输出时红绿 Highlight 对照）

1. 高档被拒：老板觉得低档高档差别不大 → 尊重节奏先低档养量，别硬推
2. 零消耗买家：买来纯管理全员关额度 → 识别「管理型」vs「消耗型」，管理型不指望消耗
3. 预算卡壳半年：融资失败+安全方案几十万卡住 → 拆开谈（安全权益已下放 AI 版，先小步用）
4. 工具栈不匹配：客户自研 coding 工具认为平台浅 → 先探清真实工具栈，别硬推
5. 硬推无场景 = 消耗低无后续 = 饮鸩止渴 → 先挖场景再推，没场景宁可不签

## 冷静期应对（ROI 核算期，待与 CSM 协同展开）

- 信号：客户开始要场景人效数据、拆分场景选型、不再敞开用
- 主动给数据：提前备好场景人效报告，别等 C-level 来要
- 帮客户做场景规划：主动占住核心场景，别让客户自己拆完把飞书拆出去
- 传递长期价值：大额不再支持多次小额充值 → 讲清一次性投入逻辑
- 管控诉求：先开放试用半年，有产出再谈管控
- 协同分工草案：RM 给数据讲价值，CSM 挡管控做陪伴

- **脱敏**：人名全去掉；企业名换成「某+行业+企业」（库玛→某大制造企业、柒牌→某服装企业、木棉花→某大消费企业）。卡片顶部标注🔒已脱敏

- **全部 Highlight**：关键数字/结论用 `<font weight=bold color=red>` 红色加粗；反例 ❌红 + 对策 ✅绿 对照
- **产品名**：Aily 已更名「豆包工作伙伴」（2026-08），不要再写 Aily
- 不写「原XX修正」这类过程性标注；重复信息（如高消耗画像）删掉

## 通用打法要点

- 知识问答是 ~85% 的 9.9 包入口（船票），关键是船后长出场景（豆包工作伙伴/妙搭/agent）
- 高管模式不是卖点，care 的客户不多，说服核心在用量
- 商务姿态：特殊 case 不硬卖（蓝星降套件折扣换包，零消耗但续约稳）
- ⚠️ 硬推无场景 = 饮鸩止渴（优优/范泰克反例：消耗低、无后续商机）
- 99 万客户规模参考：多在千人以上（富途 4000/货拉拉白领 6000/拓竹 4000），例外徕芬 1000+（关键在使用场景，见升级信号清单反直觉条）

## 交付前 Deep Grill 自审（用户要求输出前自查）

1. 区分新签/增购/续约了吗？（三类混在一起是硬伤）
2. 有升级信号量化触发器吗？（光说「用量高」不够）
3. 有失败模式/反例吗？（只有赢没有输 = 防坑缺失）
4. 资源/协同机制交代了吗？（大赛靠市场、测算靠 CSM、站台靠客户老板——新人拿到手册第一步能否执行）
5. 冷静期/竞品应对有吗？（Codex 200 万客户怎么拉回）

### 自审的最强一刀：先问「这份东西本质是什么？」

2026-08-26 实测：27 个「赢单案例」里真正的从零到一新签只有 4-5 个，其余全是「老客户额度用完续充」——等于把**增购流水账包装成了赢单方法论**，新签路径其实没提炼出来。自审时必须按此拷问每一份沉淀：

- 案例分类里，真正「新签」（9900→99000）有几个？其余是不是都是增购/续约的额度补充？
- 路径的**资源前提**交代了吗？一个没有市场资源/CSM/客户老板关系的新人拿到手册，第一步能不能执行？（不能 = 不可复制）
- 产出是「分析报告」还是「可抄作业的手册」？用户要的是后者——三类单主路径 + 量化触发器 + 失败模式速查 + 样板案例，直接能照着做
