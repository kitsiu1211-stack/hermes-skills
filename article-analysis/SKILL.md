# 文章分析（Rank-Learn-Plain v2.0）

## 🚨 硬门禁

- **先加载此 skill，再处理任何链接**。不加载即处理 = 违规。
- **卡片是唯一产出**。必须先构建 JSON → 立即发送 → 再用一句话告知已发。

## 核心流水线

```
文章全文 → ljg-rank（降秩找骨架）→ ljg-learn（挑一个概念解剖）→ ljg-plain（白话改写）→ human-writing（活人感精修）→ 飞书卡片
```

四个环节一个不能少。

## 第一阶段：ljg-rank 降秩

从文章里拉 8-12 个具体事实（数字、原话、案例）。递归下沉找到 root rank，通常 2-4 根。反生成验证：用这几根能不能把全部现象倒回来。

## 第二阶段：ljg-learn 解剖

从 rank 里挑一个最关键的概念做八维解剖。对这个用户来说，优先挑「对销售工作有直接启发」的概念。解剖结果不需要全部进卡片，只取精华——通常是压缩层的公式 + 一句话。

## 第三阶段：ljg-plain 白话

把 rank 的骨架和 learn 的解剖结果用白话重写。目标是 12 岁孩子能听懂。零术语。一句一事。具体的人和数字代替抽象概念。

## 第四阶段：human-writing 最终输出

在 plain 的基础上用活人感精修。same 禁用规则（冒号、破折号、"不是…而是…"、路标词）。最后一块必须讲"对你有什么用"，拉回销售工作。

## 分级质检（v2.0，产出物决定质检方式）

| 场景 | 质检方式 |
|------|----------|
| 常规分析（内部存档、练手） | 自查清单 + 可选脚本检查 |
| 高价值（要发出去/发客户/用户说重要） | 自查 + **外派独立 Evaluator** |

自查清单（交付前逐条过）：
- 有具体人名、数字、原话、案例吗？
- 有「对你有什么用」吗？
- 有禁用词（冒号/破折号/不是…而是…/路标词）吗？
- 每块只讲一件事吗？

外派独立 Evaluator（高价值必做）：
- delegate_task 起独立子 agent，上下文隔离，只看「卡片 + 原文全文」
- 异构优先：flash 产出 → pro 审查，或换模型家族
- 输出是**具体修改点清单**，不是评分
- 只修真问题，不为了改而改

## 卡片输出

Python json.dumps 构建。Header 用来源 + rank 的核心判断。3-5 个内容块，hr 分隔。发 Home 私聊。

### 写法标准

- 有具体的人名、数字、原话、案例。不写"有人觉得…"，写"张三说…"
- 有判断，知道哪句话值得放进去
- 每块讲一件事，讲完就停。不追在后面替读者解释
- **禁用**：冒号、破折号、"不是…而是…"、"值得注意的是"、"更深一层"、"真正的问题"、"说白了"、"先说结论"
- 最后一块讲清楚"对你有什么用"，把文章拉回销售工作

### 卡片格式

Python json.dumps 构建。Header 用来源 + 降秩后的核心判断。3-5 个内容块，用 hr 分隔。

发 Home 私聊 `oc_e2f79ec1614a1efe1ebcd7c679bb45a8`。

### 输出铁律

- 卡片优先，不发纯文本
- 分层留白，每块不超过一个手掌能遮住的文字量
- 可行动，最后一块必须讲怎么用在客户对话里
- lark_md 支持 `**加粗**` 和 `\n`，禁用 `##` 标题和 markdown 表格
