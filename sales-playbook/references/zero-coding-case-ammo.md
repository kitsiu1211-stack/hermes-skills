## 三个「零技术背景」案例（按说服力排序）

### 1. 贺馨｜华东师范大学传播学研究生｜电商直播达人样品管理工作台
**标签**：纯文科生 + 第二次 vibe coding + 接了外部 API（顺丰开放平台）

- 痛点来源：美妆品牌抖音部门实习做达人直播商务助理（自述「快递小妹」），一个暑假下了 100+ 顺丰单；库存更新不及时、地址来微信群、单号在顺丰、寄样去向不明。
- 产出：工作台打通「导入目录 → 按常用状态设库存安全线（嵌套 IF）→ 新建寄样自动匹配商品名并扣库存 → 顺丰 API 同步物流 → 调货追踪自动回补」。
- **可引用原话**：「零技术背景的人想搭工作台，只要能讲清楚自己的需求，现在已经没什么技术壁垒了。」
- **踩坑三连（对客讲最加分，说明我们教的是真方法不是话术）**：
  1. 贪心想让工作台接管全部工作 → 让 AI 先给「最小链路闭环」方案，明确「先保留哪些功能」，并要求只讨论方案不要动手改。
  2. API 接入只需要提供 ID + 密钥；把平台开发者指引链接**直接丢给 AI 让它读**；沙箱测试满 3 次即可上生产。
  3. 报错 A10004「没有对应服务权限」→ **「不能什么都交给 AI，还要自己动一下脑子」**：去开放平台 FAQ 查、必要时找人工工程师客服。
- 结论口径：**零技术背景不是壁垒，但 AI 也不是万能**——配套话术是「我们陪着客户一起解决」，不是「交给 AI 就行」。

### 2. Lucian（刘文昌）｜冶金/钢铁专业｜AI 村口情报中心
**标签**：非计算机专业 + 完全靠飞书 CLI + 已商业化变现

- 作品：自动找赛事 + 提醒报名截止，Skill 已上架豆包工作市场，别人可直接拉来用；累计获利 1 万+。
- 搭建方式：**飞书 CLI 当「人和 AI 之间的工具手」**——把想法告诉它，全部操作它完成。他给社区的建议：「想学多维表格？直接装飞书 CLI，把想法告诉它。」
- **关键差异（可选差异化论点，需现场验证）**：其他 AI 抓微信公众号易触发反爬（robots.txt）、活动海报是图片抓不到，**豆包工作伙伴能成功提取**。
- 金句：「别让消息只在村口路过。」（可借用为「别让机会只躺在收藏夹里」）

### 3. MONA｜跨境电商日语本地化翻译｜台词切片机
**标签**：完全用妙搭 + 自然语言描述 + 靠迭代磨出精品

- 作品：上传台词截图 → 自动拆解语法/知识点 + 讲义 → 台词手账；另有共享广场、隐私锁、闯关小游戏、飞书一键登录。
- **迭代数据**：一共发了 **91 个版本**；观众夸 UI 好看，她的回答是「我调了好几次，我要求也比较高」。
- 可复用技巧：妙搭的「编辑」功能可对页面**单个元素**写要求 → 点对点局部优化，不用整页重做。
- 主动取舍：为让用户**不限次数免费用**，主动选免费大模型（代价是慢一点）——提前说明，避免被当产品缺陷。**这条对客讲很有用：AI 应用的成本结构是客户没说出口的顾虑。**

## 产品能力侧的佐证（配合上述案例一起讲）

- **外部系统对接**：贺馨接顺丰 API、江月（AI 产品经理）接公司内部 API 做库存运营 Agent——证明「连外部系统」是客户可自己走通的路径。
- **复杂任务**：林凯明摄像头智能巡检 demo（接入公开视频源 + 14 点位仿真 + 妙搭平台 + MCP 服务 + 豆包工作自定义连接器），产出 HTML/PPT/巡检报告，还能自动放大关键帧、框定问题点位。⚠️ 但**速度是短板**（10 分钟以上，约 WB 的 2-3 倍）→ 讲闭环不讲速度。
- **交付物形式**：PPT / Excel / 画布 / 多维表格 / 妙搭看板——客户问「产出能落在哪」时可直接列举。

## 顺手记下的活动形式（对外分享可复用）

这场直播作为「社区用户实机 demo 分享」的样本，比内容本身更值得抄：
- **7 分钟倒计时 + 观众扣「加时」**：把节奏压力交给观众投票，既控时又有互动。
- **强制讲踩坑**：主持人明确说「这次跟往期不一样的是，我强制要求他们聊自己怎么搭的、踩了什么坑」——这一条决定了信息密度。
- **给观众一个代入问题**：「如果换成是我自己的需求，他这个方法我能不能用？」
- **资料包一页收口**：7 个工具的指南 + 前 8 期回放全在一份文档里，弹幕反复贴，入口唯一。
- **常设征集入口**：做过作品的人可下次上台，活动自我循环。
