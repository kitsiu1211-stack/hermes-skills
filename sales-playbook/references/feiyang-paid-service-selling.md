# 飞鹰（付费服务包）老客售卖打法

来源：2026-10-12「服务大荟堂第 20 期｜区域实战」王浩分享（静默旁听逐字稿）+ 同场 RM 周会的续约救单配置。
适用于**已在付费、服务阈值被养高、时不时要求降价/多送东西**的老客（尤其互联网类客户）。

---

## 一、客户画像：先确认你的客户是不是这个病

- 用飞书很多年、买了很多产品、客单价高；生意有周期性 → 被要求降价的频率高
- **服务阈值被养得极高**（飞书服务太出名）：CSM/销售响应慢一点，客户就把协同部门、辅助部门、CSM、销售全拉进一个群 → 销售时间被严重碎片化
- 客户侧业务部门同样痛苦（「找不到你们人」「服务没以前好了」）→ 出现过投诉
- 销售手里「牌不多」：不能停服、不能真降价、没有赠品预算

→ 飞鹰是这套困局的解法：**它同时解决客户的响应焦虑和销售的降价压力。**

## 二、踩过的弯路（务必绕开）

「钢铁直男直接去卖」＝ 见客户就说「这是飞鹰，给你做服务升级」→ 客户的典型三连问：

1. 「你是不是来骗我钱？」
2. 「为什么要硬塞给我这个东西？」
3. 「我们不是有 CSM 吗？我买了产品，为什么还要花钱？」

**正确时机 = 续约 / 增购节点。** 飞鹰在订单上有独立金额，客户感知到的是「原来那部分有降价、同时内容还更多了」，总价不涨、内容变多 → 对高风险客户能**保住原有 ARR**；放在大订单 BOM 里客户对清单更有体感。

⚠️ **铺垫必须前置**：日常聊客户时就顺带提飞鹰，等到大单续约才第一次铺垫「其实有点晚」。

## 三、两个必须跟客户达成的共识

**① 态度坚决不降价** —— 「说最软的话，有最坚硬的态度」：同价之下给你更多服务。底层逻辑是把关系从甲乙方说成**利益与目标的共同体**（对接人也要完成自己的指标，我是在帮他也在帮我自己）。

**② 把服务入口从销售/CSM 身上剥离** —— 原话要反复跟客户和各部门讲：「有事不要来找我，也别来找 CS，**我们都不是客服**」。
- 让客户先走**官方客服通道**，自己跑通一遍拿到效率基线，再对比飞鹰（「我跟他说太多，不如他自己跑一遍」）
- 配套动作：跟 CSM 打配合，让 CSM **适当慢一点 push**——「CSM 不是客服，别为难自己，看不过来的消息就别回了」。**有收有放，客户才有感知**
- 复杂问题追工时时，让 CS 直接说「这个问题飞鹰更合适，我找会比较慢」——这是坦诚清晰，不是拒绝客户

**🚫 绝不白送**：原话「我绝对不会白送这样的服务，**它是有绝对价格的，不是一个赠品**」。要换就拿真金白银或更多订单来换。
一旦第一单被当赠品送掉：价值感归零 → 后面每单都被要求送 → 客户用着也不珍惜 → 后续增购/续约都失去杠杆。

## 四、飞鹰 4.0 怎么讲（分享者自述「没理解得很透彻」，对客前先跟官方口径对齐）

| 卖点 | 讲法 |
|------|------|
| **专属感 / 尊贵感** | 类比迪士尼会员：专属通道、专属团队、专属节目，服务高净值人群 |
| **定位在技术支持** | CSM 没有技术背景，深水区问题销售和 CSM 都头疼、不停拉人、服务成本高；飞鹰背后的技术团队背景更深 |
| **卖「确定性」不是「更快的通道」** | 出问题有人管、复杂问题有人扛；官方客服通道做不到（相对弱、时常换人、订单结束就走） |

## 五、三个让客户产生体感的动作

1. **每个工单群 / oncall 群只要有客户，就在群里宣传飞鹰** —— 「讲很多 PPT 都不如他自己在群里实时体验一下」。客户走完排队、部门流转后，再看到飞鹰专属群「着急时、深夜时、放假时都有人直接拉群跟进闭环」，反差极大
2. **CSM 适当慢一点**（见上）
3. **复杂问题让 CS 说出「飞鹰更合适」**（见上）

**试用策略：挑人、不全量**。全量试用成本高且拉长关单节奏；只选关系好的客户，客户有汇报/采购诉求时引入。判断：「用过飞鹰之后，采购飞鹰是大概率的事」。

## 六、真实案例（可直接转述）

节前某客户体验期，晚上 6 点多机器人错发消息给 20 多个高管（涉及薪酬/组织架构调整），客户疯狂找人 → **飞鹰 1 小时内解决**，客户很惊讶（走客服会很久，而且是假期前一天晚上）。

## 七、三点总结（对客/对内部都可用）

1. **创收的隐形钥匙**——还带动其他产线增量
2. **续约与增购的杠杆**——老客商务压力越来越大、老产品线受挑战
3. **三方解放**——客户、CSM、销售自己都从客服与投诉的困局里出来

## 八、配套：续约风险救单的标准配置（同场 RM 周会，负责人原话）

销售 + 售前 + CSM + 高层，**四人一起上**：

1. CSM 先做 5–10 分钟**服务复盘**稳住场面（我们做了很多事、你们用得不错、换掉的使用成本很高）
2. 售前讲 AI 未来能做什么——**很多客户、尤其一号位根本没好好听过 AI**
3. **高层必须约到 CIO 以上**，最好老板和 CIO 一起（风险常产生在 CIO 层，而老板其实认价值，只是没听到）
4. 心态：**所有子弹都要打出去**，「能救回来就救，救不回来不留遗憾」；**底线价格由后手出**，销售不先亮底

配套的预算话术（续约节点）：对客户的对接人来说，临时要预算最难，**续约时一把把钱要够是对他工作的支持**——「你当时把预算做好，再临时要钱是要不来的」。

## 九、给本人的结合点（按 RM + AI 专项身份）

- 团队 Q4 明确把「服务货币化 × 豆尊切换」绑在一起推（原话：切豆尊时「再塞一两个飞鹰」，FDE 形式呈现、AI solution 类可算业绩）→ 本文件是现成话术
- 手上「服务阈值高 + 有投诉史」的客户（如安全信任危机类）最适合借用「先走官方通道拿对比 + CSM 有收有放」
- 分享者自己没吃透飞鹰 4.0 定位 → 要在专项会给销售做输入前，**先确认官方口径**（尤其「卖确定性」这个说法是否与现行产线口径一致）
