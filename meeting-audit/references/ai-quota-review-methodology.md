# AI 商机盘点方法论

## 触发

用户与 RM 逐客户盘点 AI 包。旁听脚本自动捕获，会后从 transcript 提取。

## 商机标签分层

```
🔴 首购-推9.9        未购客户
🟢 加速消耗-正常       自然增购，产出标杆
🟡 加速消耗-需CSM      低消耗，CSM重点投入
🔵 高层建联-教育        CIO/CTO推研修班/活动
🟣 高层建联-触达        PR/市场协同
⚫ 低优-无决策人        放弃
```

## 购买动因分类

| 原因 | 占比 | 增购潜力 |
|------|:---:|:---:|
| 知识问答 | ~85% | 高(场景长出后自然增购) |
| 随飞书上线捆绑 | ~10% | 中(需后续服务驱动) |
| 硬推 | ~5% | 低(消耗差，无场景) |

## 增购路径

```
知识问答 → aily(垂类) → 妙搭/电商skill → 29.7/99万   [场景自然生长]
知识问答 → CSM推智能伙伴 → 消耗暴增 → 29.7           [服务驱动]
知识问答 → 用得保守 → 低消耗 → 无商机                [需干预]
```

## 跨行业分析维度

- 核心驱动场景
- 组织阻因(AB面恐惧/不稳定/没找对人)
- 决策人类型(CEO/CIO/CTO/CAIO)
- 增购驱动力(消耗自然/CSM推/商务手段)
- 竞品威胁(豆包企业版/自研agent)
