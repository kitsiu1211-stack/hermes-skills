# Token 消耗分析

## 当前状态

- 243 个 skill 全部注入每轮 system prompt
- 每个 skill 名 + 描述 ~80 chars → 243 × 80 = 19,440 chars
- 中文内容约 3.5 chars/token → ~5,554 tokens / turn
- 实际每次对话只用 3-8 个 skill

## 优化路径

### 路径 1：同 Profile Zone 路由（已实施）

每轮 system prompt 仍注入全部 243 个 skill（~5554 tokens），但只加载命中 Zone 的 skill 全文。

**节省**：减少 skill_view 调用次数（8→4），节省 skill 全文加载 Token（每篇 ~2000 chars ≈ 570 tokens），一轮交谈省 ~2,280 tokens。总节省约 10-15%。

### 路径 2：拆 Profile（待实施）

每个 Profile 只加载 30-50 个 skill。

| Profile | Skill 数 | 每轮注入 | 节省 |
|---------|---------|---------|------|
| 当前（全量） | 243 | ~5554 | — |
| 工作-会议/销售 | 40 | ~914 | 84% |
| 工作-阅读 | 25 | ~571 | 90% |
| 生活 | 15 | ~343 | 94% |
