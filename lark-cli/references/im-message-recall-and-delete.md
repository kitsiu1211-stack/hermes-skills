# 飞书消息「撤回 / 删除 / 存储口径」知识库

场景：用户问「有没有批量删除聊天信息的方法」「删了聊天记录能不能释放存储」「客户问员工自己删聊天记录管不管用」。
结论先行：飞书**没有「一键删除整个会话」的开关**，四条路各管一段，选错就会对客户做出错误承诺。

## 0. 四条路的边界（先看这张表）

| 路径 | 谁能做 | 影响范围 | 释放存储 |
|---|---|---|---|
| 客户端多选删除 | 任何人（限自己视图） | 只删自己这一侧 | ❌ |
| 客户端撤回 | 消息发送者本人 | 全员可见地消失 | ✅（撤回原始文件才释放） |
| 管理后台批量清理聊天文件 | 超管 / 有文件管理权限的管理员 | 企业级，按时间·用户·大小圈选 | ✅ 官方唯一的真「批量」 |
| 开放 API 单条 / 批量撤回 | 机器人（仅自己发的）/ 群主（群内任意） | 视身份而定 | ✅ |

## 1. 客户端（个人）

- **批量删 = 消息多选 → 删除**：长按/右键任一条消息 → 多选 → 勾选多条 → 底部「删除」。普通聊天下多选的动作集是「合并转发 / 逐条转发 / 添加任务 / 快捷操作 / 删除」。想清空整个会话＝会话列表长按/右键 → 删除聊天。
- 🚨 **删除 ≠ 撤回**：删除只从**自己的视图**移除，对方那边仍在；只有撤回才是全员移除。
- 撤回受**企业管理员在管理后台设置的撤回时限**约束，超时后不再支持撤回。

## 2. 企业管理员批量（官方「批量」只有这一条）

管理后台 → 存储空间 → 存储清理 → **聊天文件** → 去清理：按**时间 / 用户 / 文件大小**圈选，批量创建清理任务；支持「清理成员范围 → 仅全部离职成员」。权限：仅超管或有文件管理权限的管理员（子管还需被分配存储权益才看得到入口）。清理对象是**文件**，不是文字消息。

## 3. 开放 API（要真批量、可脚本化只有这条路）

| 能力 | 接口 | 限制 |
|---|---|---|
| 撤回单条 | `DELETE /open-apis/im/v1/messages/:message_id` | 机器人只能撤自己发的；**群主可撤群内任意消息（≤1 年）**；群内机器人撤他人消息须是群主/管理员/创建者 |
| 批量撤回 | `DELETE /open-apis/im/v1/batch_messages/:batch_message_id` | **只能撤「批量发送消息」接口发出的消息**（`bm-` 开头），异步、有延迟 |
| 查进度 | `GET /open-apis/im/v1/batch_messages/:id/get_progress` | 只能查 30 天内的任务 |
| 限频 | 1000 次/分钟、50 次/秒 | 脚本循环足够 |

- 单条撤回权限（开启任一即可）：`im:message` / `im:message:recall` / `im:message:send_as_bot`；批量撤回用 `im:message:send_multi_users` / `im:message:send_multi_depts`
- 常见错误码：`230009` 超撤回时限 · `230026` 无权撤回该消息 · `230027` 缺权限/未授权 · `230110` 消息已被删除 · `230002` 机器人不在群内
- **没有「传一批 message_id 一次撤回」的接口** → 真批量＝`im +chat-messages-list` 拉列表 → 循环 `lark-cli im messages delete --message-id om_xxx --yes`。该命令是 **high-risk-write**，只有用户明确确认后才可以加 `--yes`
- 机器人撤回**别人发的**消息，必须机器人本身是群主/管理员/创建者 → 一般只能用群主身份的机器人撤群内消息

## 4. 存储容量口径（对客必背，最容易踩坑）

- 🚨 **员工自己删聊天记录 / 清空聊天 → 不释放企业存储空间。** 只有管理员后台清理 IM 文件、或发送者**撤回原始消息**，才真正释放容量。别答应客户「让员工自己删就能腾空间」。
- IM 计容只算 **图片 / 视频 / 本地文件 / 文件夹** 四种；**文本消息、云文档链接、表情包不计容**。
- 群内发本地文件只算一份（50 人群发一张 100M 图片＝100M，不是 ×50）；改成分别单聊发则各算一份（A→B/C/D 各发 10M＝30M）。
- 文件先上传云空间、再以**云文档链接**在 IM 里分享 → 计入「云文档」而非 IM 占用，是引导客户降容量的标准话术。
- 转发的消息文件会生成副本、各算一份；**原始文件被撤回后，被标记/转发的副本也会同步撤回并释放全部占容量**。
- 查看路径：客户＝管理后台 → 容量概览；销售/CSM＝C360（C360 为准，多维表格里的数是上线前的预估、不实时）。
