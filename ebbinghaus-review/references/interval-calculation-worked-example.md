# 艾宾浩斯间隔计算 — N 轮次递进算法（2026-07-27 更新）

⚠️ **本示例覆盖 N 轮次递进算法（2026-07-19 修复版）**。旧版 flat 间隔系统（直接检查 3/7/15/30/60 天是否命中）已废弃，原因见 SKILL.md 的「间隔递进算法修复」章节。

## 核心算法回顾

```
1. 读取概念文件的「📌 每日对话」区块，统计已有复习次数 N
2. 根据 N 确定本次应检查的间隔 I:
   - N=0 → 不参与间隔匹配（走优先级 3：30天内更新过但从未复习的概念）
   - N=1 → I=7 天
   - N=2 → I=15 天
   - N=3 → I=30 天
   - N=4 → I=60 天
   - N≥5 → 退役（优先级最低）
3. 检查「距上次复习天数」D 是否落在 I ± 容差内（I≥15 时容差 ±3，否则 ±2）
4. 严禁同时检查多个间隔——每个 N 只对应一个 I
```

### 筛选过程

1. **单命中**：仅「主题21-AI原生组织建设」落在对应范围内（N=3, 30天间隔, 27天距上次, 范围27-33 ✅）
2. **无多命中排障**：只有一个命中，直接选定
3. **无 N=0 概念冲突**：因为有一个精确命中，N=0 概念（优先级3）不参与竞争
4. **防重复检查**：
   - 间隔轮次一致：N=3 应检 30d，本次距离上次（6/30）27d，确实是第 4 次复习的正确间隔
   - 每周综合复盘互斥：搜索确认无「每周综合复盘」标签覆盖本周，`_weekly-reads.md` 是周日深读推荐，非同一机制
   - 纵深类比防重复：全局搜索 `纵深：` 确认新类比（抄经院→印刷术→AI）从未使用过

## 执行技巧

- 用 `search_files(output_mode="content")` 拉全量复习记录 → 手工提取 N 和 D → 对照规则表（上述）逐个判断
- 未复习概念（N=0）用 `search_files(target="files")` 枚举所有 .md 文件，减去已有复习记录的概念得到列表
- 文件修改时间（`os.path.getmtime`）给出「何时更新过」，可作为 N=0 概念的时效性参考
- 本机 `execute_code` 在 cron 场景被封锁，用 `terminal` + python 或手算
