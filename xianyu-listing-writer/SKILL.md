# 闲鱼发布文案生成

## 平台核心规则（必须遵守）

### 1. emoji 禁用
- 标题和正文中**严禁使用任何 emoji 表情符号**（包括但不限于 🚀🔥✅⭐💎📩✔️ 等）
- 标题中的 "|" 竖线是允许的，但其他特殊符号尽量保持克制
- 正文排版用「」【】· —— 等中文标点替代 emoji 的分隔和强调作用

### 2. 短标题限制
- 闲鱼短标题（发布时第一个标题输入框）：**最多 20 个字，含空格和标点符号**
- 长标题（第二个标题输入框）：**最多 50 个字**
- 20字短标题必须写完核心卖点：身份背书 + 关键词 + 价值点
- 写完后必须严格逐字计数

### 3. 正文风格
- 闲鱼用户浏览耐心极短，正文必须**分段清晰、bullet point 化**
- 用「-」「·」「>」等纯文本符号做列表分隔，不用 emoji
- 身份背书要出现在正文**前三行**内
- 正文不宜过长，控制在手机屏幕 3-5 屏内

### 4. 定价锚点策略
- 第一档（最低价）不低于 ¥49，否则拉低信任感
- 推荐三档式结构：入门包（¥99） / 实战包（¥399/¥499） / 陪跑包（¥899/¥999）
- 中间档是实际主卖品，低价档和高价档分别做引流和锚定

### 5. 配图建议（至少 4-6 张）
- Cover 图：白底大字 + 核心卖点
- 个人分享/培训照片（面部可打码）
- 案例截图/方案截图（关键信息打码）
- 效率对比图（如"之前 3 小时 -> 现在 30 分钟"）
- 交付物截图（资料包/模板/提示词库）

## 双模块设计

此 skill 分为两个模块：

### 模块一：Generator（生成器）

根据用户输入生成完整的闲鱼发布文案，包含：

1. **短标题**（20字内，逐字计数）
2. **长标题**（50字内）
3. **正文**（按标准结构组织）
4. **配图建议**（至少4张）

生成器的输入格式要求：
```
用户背景：...
核心技能：...
差异化背书：...
服务范围：...
目标人群：...
```

生成器需要主动向用户收集以上信息（如果用户没有一次性提供全），不要遗漏任何一个字段。

### 模块二：Evaluator（评估器）

生成完成后，必须使用评估器对全文做质量检查。评估器输出一份结构化审核报告：

```
[审核报告]
总评分：X/10（低于8分需重新生成）

1. 短标题字数检查：
   实际字数：XX字（含空格和标点）
   结果：通过/不通过（超过20字不通过）

2. 长标题字数检查：
   实际字数：XX字（含空格和标点）
   结果：通过/不通过（超过50字不通过）

3. emoji 检查：
   全文是否含 emoji：是/否
   结果：通过/不通过（含 emoji 不通过）

4. 身份背书位置：
   第X行出现，符合/不符合前三行要求

5. 正文结构检查：
   - 分段清晰：通过/不通过
   - 有明确目标人群：通过/不通过
   - 有交付描述：通过/不通过
   - 有筛选标准：通过/不通过

6. 定价检查：
   最低档是否 >= 49元：是/否
   是否使用三档结构：是/否

7. 可读性检查：
   是否有大段文字堆砌：是/否
   bullet point 是否合理：是/否

8. 整体判断：
   文案是否具备推荐/转发的潜力：是/否（如果否必须重新生成）

问题清单（如有）：
- [具体问题]
- [具体问题]
```

**评估不通过的处理：**
- 总评分 < 8/10：回到 Generator 重新生成，带着审核报告指出的问题
- emoji 不通过：直接全量替换所有 emoji 为中文字符，重新审核
- 短标题超20字：精简到19字内重写，重新审核
- 身份背书不在前三行：调整正文结构，重新审核

## Generator 的生成流程

### Step 1: 明确用户信息

获取用户的以下信息：
- **行业/岗位**（如：大厂SaaS商务10年）
- **核心技能**（如：客户动态监测、商务方案编写、Leads分析、AI辅助流程）
- **差异化背书**（如：多次团队/区域分享、有理论+实践、真实案例）
- **服务范围**（能提供什么：1V1咨询、案例分享、模板输出、陪跑等）
- **目标人群**（写给谁看：商务从业者、销售、创业者、求职者等）

### Step 2: 生成短标题（20字内）

公式：`[身份/经验] + [关键词] + [价值点/结果]`

关键：**20个字**极其有限，必须做到每个字不可删减。写完逐字计数（含空格和标点）。

注：短标题有时会被闲鱼截断显示，重要信息要放在前12-15个字。

**示例（20字内）：**
- 「前大厂区域经理 ToB商务AI实战提效」（15字，不含空格）
- 「大厂SaaS十年商务 教你用AI提效」（15字）
- 「大厂SaaS商务经验 AI辅助全流程」（14字）

### Step 3: 生成长标题（50字内）

公式：`[短标题展开] + [更具体技能] + [交付方式/人群]`

长度：不超过50个字，逐字计数。

### Step 4: 生成正文

结构模板（按顺序）：

```
▨ 关于我
[个人背景 2-3行]
[核心差异点 1-2行]

▨ 能帮你什么
- [服务项1：简短描述]
- [服务项2：简短描述]
- [服务项3：简短描述]
- [服务项4：简短描述]
- [服务项5：简短描述]

▨ 适合谁
- [人群1]
- [人群2]
- [人群3]

▨ 交付方式
A [入门包 ¥99]
- 包含内容清单
- 1次30分钟1V1沟通

B [实战包 ¥399/¥499]
- 以上全部
- 3次深度辅导
- 完整工作流/框架

C [陪跑包 ¥899/¥999]
- 以上全部
- 4周系统陪跑
- 团队级方案

▨ 一些说明
- [诚信声明/筛选标准]
- [建议先私信沟通]
- [不接的人群/场景]
```

### Step 5: 配图建议

输出至少4条配图建议，每条包含图片内容和文字标注：

```
图1：Cover图 - 白底大字「[核心卖点]」
图2：[用途] - [具体内容说明]
图3：[用途] - [具体内容说明]
图4：[用途] - [具体内容说明]
```

## Evaluator 的执行时机

每次 Generator 产出文案后，**必须**立即执行 Evaluator。Evaluator 输出审核报告后：

1. **一次性通过**（≥8分且无硬伤）→ 交付给用户
2. **不通过**（<8分或有硬伤）→ 带着问题返回 Generator 修改，修改后重新评估
3. **迭代上限**：最多迭代3次，3次仍不通过则输出当前最佳版本 + 残留问题清单，由用户决定

## 定价规则

| 档次 | 价格范围 | 内容 | 定位 |
|------|---------|------|------|
| 入门包 | ¥59-¥99 | 1次咨询 + 1份模板 | 引流筛选 |
| 实战包 | ¥299-¥499 | 多次辅导 + 案例拆解 | 主力盈利 |
| 陪跑包 | ¥699-¥999 | 系统陪跑 + 团队方案 | 锚定增值 |

- 中间档价格约是入门档的 3-5 倍，价格锚点感最强
- 不建议做 ¥9.9 或 ¥19.9 极低价，会直接拉低"大厂"身份可信度

## 服务边界与买家话术（2026-10-13 新增）

虚拟服务的买家最常问的一句话是「**你这个怎么赚钱？**」——这是**责任陷阱**，不是咨询需求。

### 把问题拆成三类再回

| 类别 | 举例（Fiverr 场景） | 能不能承诺 |
|------|------|------|
| 技术性 | 账号能否正常上架、发布是否合规 | ✅ 能交付 |
| 内容性 | 标题/标签/套餐/定价/封面怎么写 | ✅ 能交付 |
| **市场性** | 有没有订单、排第几、多久出第一单 | ❌ **绝不能承诺** |

**一旦正面回答"怎么赚钱"，就等于承接无限责任**——后续没出单会被回头问责：「你说的方法没用」。

### 通用回复骨架

1. 先划边界：我交付的是「把东西正确地发布出去 + 按能卖的结构写」，不是「教你赚钱」；后者涉及选品/语言/排名/交付，是长期运营，不承诺结果
2. 给二到三档具体选项（低价档=自己按手册做 / 中档=我代做交付物 / 高档=带你做 + N 周答疑）
3. 收口句（防免费教学）：**「这些细节手册里都有，你按低价档走一遍就明白了；真卡住了再找我，中/高档我一次性帮你解决。」**

### 铁律

- **不承诺收入、订单量、排名、时间**；只承诺「流程跑通 + 按模板交付 + N 次答疑」
- 高档卖的是「**带你做**」，不是「教你赚钱」——措辞差一个字，责任天差地别
- 高耗低意向信号（问赚钱、问保底、反复索要免费细节）→ **3 句收口**，不成即礼貌结束；为成交开始免费教学是最亏的
- 交付物必须留痕可验收（发布的截图/链接），并把边界写进闲鱼详情页，不只写在聊天里

## 常见坑位

- 「一套提示词让你年薪百万」这类标题在闲鱼上反而会被当成骗子
- 接受"先私信沟通"会让用户感觉你在筛选客户，提升信任感
- 正文写"只接有基础的"反而能提高转化率——筛选感 = 专业感
- 如果交付包含在线文件，注意闲鱼不能直接发外链
- 配图上的字不要太小，闲鱼大部分流量是手机端浏览
